## Calibration activity logs now show the user name

Calibration-related activity logs now include the user name, making it easier to see who performed the action and to review device history more clearly.

## Fixed an issue where Bluetooth only mode could not be manually disabled during an incident-like state

In some cases, the app showed an unhealthy API state without creating a real incident. If the user manually disabled Bluetooth only mode, the app could re-enable it again after pull to refresh. This is now fixed, so Bluetooth only mode stays disabled when the API is actually working.
