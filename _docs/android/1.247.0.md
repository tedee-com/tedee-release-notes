## Calibration activity logs now show the user name

Calibration-related activity logs now include the user name, making it easier to see who performed the action and to review device history more clearly.

## Faster loading of the lock details screen

Opening a lock now shows its current state and available actions sooner. The screen prepares the data it needs in the background instead of waiting for everything to arrive, so there is less waiting before you can lock or unlock.

## More reliable operation when the phone switches between Wi-Fi and mobile data

When you left home or moved out of Wi-Fi range, requests started on the old connection could hang or fail. The app now notices the network change and reconnects right away, so commands and status updates keep working while the phone switches between Wi-Fi and mobile data.

## Faster Auto-Unlock thanks to reused secure connections

Auto-Unlock now reuses an already established secure connection to the lock more often instead of setting up a new one every time. The door opens sooner as you approach, especially at locks you use several times a day.

## Fixed the privacy policy link

The privacy policy link in the app opened the wrong page. It now takes you directly to the current privacy policy.

## Prominent disclosure for location access

Before the app asks for location permission, it now explains why the permission is needed — location access is used for Bluetooth scanning and Auto-Unlock, including while the app runs in the background. This follows Google Play requirements, and the data is not used for anything else.
