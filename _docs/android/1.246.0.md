## Faster unlocking for locks used over Bluetooth only

If you have access to a lock without remote control — for example a shared office door — unlocking now happens noticeably faster. The app connects to the lock quicker and keeps the connection ready longer, so a second unlock at the same door responds almost immediately.

## More reliable Auto-Unlock on phones with aggressive battery saving

On some phones the Bluetooth scan could go quiet while the screen was off, and Auto-Unlock would stall if you were still far from the lock. The app now keeps checking throughout the whole approach, so the lock is detected as you get closer.
